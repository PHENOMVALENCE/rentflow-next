# UI/UX Design

## Information architecture

### Public
Home, Listings, Listing detail, Help/Contact, Sign in.

### Tenant
Home, Lease, Payment/Renewal, Agreement, Maintenance, Notices, Receipts, Profile.

### Landlord/Admin
Dashboard, Properties, Units, Listings, Tenants, Leases, Payments, Agreements, Supervisors, Maintenance, Notices, Reports/Audit, Settings.

### Supervisor
Assigned properties, Maintenance queue, authorized tenant contacts, notices, operational tasks, profile.

## UX rules

- Fixed payment amount is displayed, never freely entered.
- Pending payment is visually distinct from confirmed success.
- Countdown always includes exact date/state context.
- Public listing never reveals tenant/lease/payment details.
- Admin publishing explains occupancy blocks.
- Supervisor interface excludes unrelated portfolio financial data.
- Maintenance status history is explicit.
- Safety notices are visually distinct from ordinary community messages.
- Mobile is a first-class layout, not a shrunk desktop screen.
